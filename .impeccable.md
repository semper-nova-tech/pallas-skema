## Design Context

### Users
The Human reviewer arranges one Diagram on a Grid and checks it against the Manifest. The Agent edits the Manifest as text and is not the person looking at this screen.

### Brand Personality
Precise, calm, terminal. The tool should feel like a local instrument, not a marketing site.

### Aesthetic Direction
Dark green-on-black terminal. Controls sit on the left. The main area is a fixed canvas with a dot grid. Node type is labeled in words as well as color. Anti-references: generic Material stacks, purple gradients, neon glow, and a page that looks like unstyled HTML.

### Design Principles
- The canvas is the product; controls stay in the rail.
- Green carries the interface; amber marks a decision; a failure uses its own red and never gray-on-color.
- Motion confirms a save or a selection and stops when the user prefers reduced motion.
- A default canvas size is an Editor view, not a Manifest field.
